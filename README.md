
# ALFAS — Plataforma de Literacia em Saúde

## Sobre o projeto

A ALFAS é uma plataforma web de literacia em saúde destinada a alunos do 3.º ciclo e do ensino secundário.

A plataforma disponibiliza formações através de webinars e workshops sobre diferentes áreas da saúde, sendo também utilizada por professores e profissionais de saúde.

## Objetivos

- Promover a literacia em saúde entre os jovens.
- Disponibilizar conteúdos educativos.
- Avaliar a evolução da aprendizagem.
- Emitir badges e certificados de conclusão.
- Disponibilizar ferramentas de gestão e análise estatística.

## Tecnologias

- Frontend: React
- Backend: Python e Flask
- Base de dados: MySQL ou SQL Server
- Arquitetura: MVC

## Funcionalidades principais

- Registo e autenticação de utilizadores.
- Consentimento parental para menores.
- Questionários de diagnóstico e avaliação final.
- Consulta de webinars e workshops.
- Biblioteca virtual e notícias.
- Badges e certificados.
- Gestão de conteúdos e utilizadores.
- Estatísticas e exportação CSV.
- Suporte para português e inglês.

## Estrutura do projeto

- `docs/` — documentação e diagramas.
- `frontend/` — aplicação React.
- `backend/` — aplicação Flask.
- `.github/` — configurações de automação GitHub.
